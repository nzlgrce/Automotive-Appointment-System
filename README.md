🚗 Automotive Appointment & Tracking Management System

This is a school project-based system for Web Development Subject.

A simple yet efficient web-based system designed to streamline automotive service appointments and track vehicle service progress in real time. This project aims to improve workflow organization for auto repair shops while providing customers with a transparent and convenient service experience.

📌 Overview

The Automotive Appointment & Tracking Management System allows customers to book service appointments and monitor the status of their vehicles, while enabling administrators or staff to manage schedules, track service progress, and maintain organized records.

This system is ideal for small to medium-sized automotive service businesses looking to digitize their operations.

✨ Features

👤 Customer Side

📅 Book service appointments
🔍 Track vehicle service status in real-time
📝 View appointment history and details

🛠️ Admin / Staff Side

📋 Manage and approve appointments
🔄 Update service progress (e.g., Pending, Ongoing, Completed)
🧾 Maintain customer and vehicle records
📊 Monitor daily operations efficiently

⚙️ Tech Stack

Frontend:(HTML / CSS / JavaScript)
Backend:(PHP)
Database:(MySQL)
